Upload a JPEG or PNG under Experience in `/admin` to change the logo for the selected Experience entry. The public portfolio uses that upload immediately after saving.

This folder provides optional fallback logos. Use the company name in lowercase, replacing spaces and punctuation with hyphens. For example, `Acme Labs` uses `acme-labs.png`. PNG, SVG, WebP and JPEG files are supported here. Rebuild the frontend after adding a file to this folder. Companies without either image display the shared placeholder.
